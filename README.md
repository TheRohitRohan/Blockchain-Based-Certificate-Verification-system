# Certificate Verification System with Blockchain

A decentralized certificate verification system using Ethereum blockchain for immutable, tamper-proof certificate records.

## Tech Stack

| Component | Technology |
|-----------|------------|
| Frontend | React.js |
| Backend | PHP 7.4+ |
| Database | MySQL |
| Blockchain | Ethereum (Ganache) |

## Default Login

- **URL**: http://localhost:3000
- **Email**: admin@certificate-system.com
- **Password**: admin123

## Features

- Issue digital certificates with blockchain verification
- Public certificate verification portal
- QR code generation
- PDF certificate generation
- Role-based access control (Admin, University, Student)
- Certificate revocation
